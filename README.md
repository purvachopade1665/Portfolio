# Purva Chopade, Portfolio

Single-page portfolio. Plain HTML, CSS and JavaScript in one file (`index.html`), no build step.
Fonts load from Google Fonts.

## Publish on GitHub Pages
1. Create a public repo (name it `purvachopade1665.github.io` for the URL `https://purvachopade1665.github.io`).
2. Upload these files to the `main` branch.
3. Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.

## Edit
Project, skill and tool content lives in the `PROJECTS`, `SKILLS`, `EXP` and `TOOLS` arrays near the bottom of `index.html`.
The photo is embedded in the `--photo` CSS variable at the top of the file.
